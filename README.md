# 로또번호 조합기 — 배포 파일

최신 버전 받기: **[Releases → Latest](https://github.com/wbslog/lotto_make_app_release/releases/latest)** 에서 `LottoMaker.exe` 를 내려받아 실행하세요.

- 설치 없이 바로 실행되는 파일 1개입니다. 원하는 폴더(예: 바탕화면, 문서)에 두고 실행하세요.
- 로그인에는 발급받은 **아이디 · 비밀번호 · 인증키(64자리)** 가 필요합니다.
- 실행할 때마다 새 버전을 확인해 자동으로 업데이트하고 다시 실행합니다.

---

## 실행할 때 경고가 뜨면

이 프로그램은 개인이 만든 프로그램이라 Microsoft 코드 서명이 없습니다.
그래서 처음 받거나 업데이트된 뒤 아래 경고가 뜰 수 있습니다. **이 페이지에서 받은 파일이라면** 아래대로 진행하세요.

### 1. 브라우저에서 "일반적으로 다운로드되지 않는 파일" 경고 (Edge · Chrome)
- **Edge**: 다운로드 목록에서 파일 옆 **`…`** → **유지** → **자세히 표시** → **그래도 유지**
- **Chrome**: 다운로드 목록에서 **유지** (또는 **위험한 파일 다운로드**) 선택

### 2. "Windows의 PC 보호" 파란 창 (SmartScreen)
1. 창 안의 **추가 정보** 를 누릅니다.
2. 아래에 생긴 **실행** 버튼을 누릅니다.

### 3. "게시자를 확인할 수 없습니다" 보안 경고
- **실행** 을 누릅니다.
- 매번 뜨면: `LottoMaker.exe` 우클릭 → **속성** → 일반 탭 아래 **차단 해제** 체크 → **확인**

### 4. 백신(V3 · 알약 · Windows 보안 등)이 파일을 지우거나 막을 때
1. 백신의 **검역소 / 치료 기록** 에서 `LottoMaker.exe` 를 **복원** 합니다.
2. 프로그램이 있는 폴더를 **예외(제외) 목록** 에 추가합니다.
   - Windows 보안: **바이러스 및 위협 방지** → **설정 관리** → **제외 추가 또는 제거** → **폴더**
3. 파일이 이미 지워졌다면 위 **Releases** 에서 다시 받습니다.

### 5. "프로그램 폴더에 파일을 쓸 수 없습니다" (업데이트 실패)
- `C:\Program Files` 처럼 쓰기 권한이 없는 폴더에서는 자동 업데이트가 되지 않습니다.
  **바탕화면 · 문서 · 다운로드** 같은 일반 폴더로 옮겨서 실행하세요.

### 6. "업데이트 서버에 연결할 수 없습니다" (설정 → 업데이트 확인 시)
- 인터넷 연결을 확인하세요. 연결이 안 되어도 프로그램은 그대로 실행됩니다.
- 계속 실패하면 이 페이지에서 최신 `LottoMaker.exe` 를 직접 받아 기존 파일과 바꿔 주세요.

> ⚠ 이 저장소(**github.com/wbslog/lotto_make_app_release**)가 아닌 곳에서 받은 파일은 실행하지 마세요.
